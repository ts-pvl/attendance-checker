# Отметка посещаемости по QR-коду

[English](README.md) · **Русский** · [Қазақша](README.kk.md)

Учёт посещаемости для школы с общими компьютерами на Linux. Ученик
отмечается, сканируя телефоном QR-код на экране компьютера. Сотрудники
видят, кто сейчас в классе и сколько часов посетил каждый ученик.

## Как это выглядит для ученика

1. Ученик входит в систему на школьном компьютере. Браузер открывает страницу с QR-кодом.
2. Ученик сканирует код камерой телефона. В Telegram открывается бот школы.
3. Бот отвечает: «Вы отметились на PC-17 ✅».
4. Когда ученик выходит из системы или компьютер простаивает 30 минут,
   посещение закрывается само. Бот присылает сообщение со временем.

Код меняется каждые 30 секунд и срабатывает один раз, поэтому фотографию
экрана нельзя использовать повторно.

## Что получают сотрудники

Веб-страница (админка), которая открывается только из сети школы:

* кто отмечен прямо сейчас и на каком компьютере;
* часы каждого ученика за день, неделю и месяц, с выгрузкой в таблицу (CSV);
* графики посещаемости, таблица посещений по дням и список необычных посещений;
* исправления с указанием причины и журнал всех изменений.

## Что нужно

| | Требование |
|---|---|
| Компьютеры учеников | Ubuntu (или другой Linux на основе Debian) с рабочим столом GNOME. У каждого постоянный IP-адрес (подойдёт резервирование в DHCP). |
| Сервер | Один компьютер с Ubuntu, который всегда включён, находится в той же сети, имеет постоянный IP-адрес и доступ в интернет. Подойдёт компьютер администратора. Отдельная машина не нужна. |
| Доступ | С сервера можно подключиться к каждому компьютеру учеников по SSH и выполнить там `sudo`. Установщик использует для этого Ansible и сам его ставит, если нужно. |
| Telegram | Бот школы (бесплатно, создаётся за две минуты у @BotFather). У каждого ученика есть Telegram на телефоне. |

Бот и веб-страницы работают на русском или английском языке (выбирается при
установке). Документация есть и на казахском.

## Установка

Всё делается на компьютере-сервере, под пользователем, у которого есть доступ
по SSH к компьютерам учеников.

**1. Создайте бота в Telegram.** Откройте @BotFather, отправьте `/newbot` и
ответьте на вопросы. Сохраните токен, который он выдаст (выглядит как
`123456789:AAE…`). Обращайтесь с ним как с паролем.

**2. Перечислите компьютеры учеников** в файле инвентаря Ansible. Если вы
уже управляете компьютерами через Ansible, возьмите свой инвентарь. Если
нет, создайте файл `~/ansible/hosts.yml`:

```yaml
students:
  hosts:
    pc-01: { ansible_host: 192.168.1.101 }
    pc-02: { ansible_host: 192.168.1.102 }
    pc-03: { ansible_host: 192.168.1.103 }
  vars:
    ansible_user: admin        # пользователь, под которым вы входите по SSH
```

Имя слева (показывается как `PC-01`) ученики видят в боте. Пользователь SSH
должен выполнять `sudo` без запроса пароля; иначе добавьте
`ansible_become_password`, как описано в документации Ansible.

**3. Скачайте и запустите установщик.**

```bash
sudo apt install git
git clone https://github.com/ts-pvl/attendance-checker.git
cd attendance-checker
./deploy/install.sh
```

Установщик задаст несколько вопросов:

| Вопрос | Что отвечать |
|---|---|
| Inventory file (файл инвентаря) | Файл из шага 2. |
| This PC's IP address (IP-адрес этого компьютера) | Адрес сервера в сети школы. Потом он не должен меняться. |
| Bot token (токен бота) | Токен из шага 1 (при вводе не отображается). |
| Time zone, language (часовой пояс, язык) | Например `Asia/Almaty`, `ru`. |
| Alert ids (ID для оповещений) | Необязательно. Telegram ID сотрудников, которым писать, если система не работает. Пока можно оставить пустым. |
| Username, password (имя и пароль) | Ваша первая учётная запись для админки. |
| Deploy to the PCs now? (установить на компьютеры?) | `y`. Чтобы сначала попробовать на одном компьютере: `./deploy/install.sh --limit pc-01`. |

В конце он напечатает адрес админки, например
`http://192.168.1.10:8080/admin`.

**4. Добавьте учеников.** Откройте админку в браузере на сервере или на
компьютере сотрудника (не на компьютере ученика: оттуда вход запрещён).
Войдите, затем:

1. *Ученики → Импорт или обновление из CSV.* В файле нужны столбцы `имя` и
   `группа` (или `name` и `group`), например:

   ```csv
   имя,группа
   Айгерим Садыкова,Python-1
   Тимур Ахметов,Go-2
   ```

2. *Создать ссылки для всех непривязанных*, затем распечатайте страницу с листками.
3. Выдайте каждому ученику его листок. Ученик один раз открывает ссылку (или
   сканирует QR на листке), и бот отвечает «Аккаунт привязан: …».

**5. Проверьте.** Войдите на компьютер ученика, отсканируйте QR-код и
убедитесь, что ученик появился на странице *Сегодня*.

## Обновление

```bash
cd attendance-checker
git pull
./deploy/install.sh
```

Установщик помнит прошлые ответы. `./deploy/install.sh --pcs-only` ставит
только на компьютеры учеников (например, после переустановки одного из них),
а `./deploy/install.sh --help` показывает все параметры.

## Частые вопросы

**Админка пишет «forbidden».** Она открывается только из сети школы и никогда
с компьютера ученика. Откройте её на сервере или на компьютере сотрудника.

**Компьютер ученика был выключен во время установки.** Установщик перечислит
такие компьютеры в конце и покажет команду, которую нужно выполнить позже.

**На компьютере не открывается страница с QR-кодом.** Проверьте, что
IP-адрес компьютера совпадает с адресом в инвентаре, и выполните
`./deploy/install.sh --pcs-only`.

**Ученик сегодня без телефона.** Сотрудник с ролью администратора добавляет
посещение вручную на странице ученика, указав причину.

**Что хранится об учениках?** Имя, группа, Telegram ID, время прихода и
ухода, исправления сотрудников. Ничего о том, что ученик делает на
компьютере. Все данные остаются на вашем сервере.

**Работает ли без интернета?** Серверу нужна связь с Telegram. Компьютерам
учеников нужна связь только с сервером.
