# Қатысуды QR-код арқылы белгілеу

[English](README.md) · [Русский](README.ru.md) · **Қазақша**

Ортақ Linux компьютерлері бар мектепке арналған қатысуды есепке алу жүйесі.
Оқушы компьютер экранындағы QR-кодты телефонымен сканерлеп белгіленеді.
Қызметкерлер қазір сыныпта кім отырғанын және әр оқушының неше сағат
қатысқанын көреді.

## Оқушы үшін қалай көрінеді

1. Оқушы мектеп компьютерінде жүйеге кіреді. Браузер QR-коды бар бетті ашады.
2. Оқушы кодты телефон камерасымен сканерлейді. Telegram-да мектеп боты ашылады.
3. Бот жауап береді: «Вы отметились на PC-17 ✅» (PC-17 компьютерінде белгілендіңіз).
4. Оқушы жүйеден шыққанда немесе компьютер 30 минут әрекетсіз тұрғанда,
   келу жазбасы өзі жабылады. Бот уақыты көрсетілген хабар жібереді.

Код әр 30 секунд сайын өзгереді және бір рет қана жарайды, сондықтан
экранның суретін қайта пайдалану мүмкін емес.

## Қызметкерлер не алады

Тек мектеп желісінен ашылатын веб-бет (әкімші панелі):

* дәл қазір кім және қай компьютерде белгіленгені;
* әр оқушының күн, апта, ай бойынша сағаттары және оларды кестеге (CSV) жүктеу;
* қатысу графиктері, күндер бойынша қатысу кестесі және әдеттен тыс келулер тізімі;
* себебі көрсетілген түзетулер және барлық өзгерістердің журналы.

## Не қажет

| | Талап |
|---|---|
| Оқушылар компьютерлері | GNOME жұмыс үстелі бар Ubuntu (немесе Debian негізіндегі басқа Linux). Әрқайсысының тұрақты IP-мекенжайы бар (DHCP-де бекітіп қою жеткілікті). |
| Сервер | Әрқашан қосулы тұратын, сол желідегі, тұрақты IP-мекенжайы және интернеті бар бір Ubuntu компьютері. Әкімшінің компьютері жарайды. Бөлек машина қажет емес. |
| Қатынау | Серверден әр оқушы компьютеріне SSH арқылы қосылып, онда `sudo` орындауға болады. Орнатқыш бұл үшін Ansible қолданады және қажет болса оны өзі орнатады. |
| Telegram | Мектеп боты (тегін, @BotFather арқылы екі минутта жасалады). Әр оқушының телефонында Telegram бар. |

Бот пен веб-беттер орыс немесе ағылшын тілінде жұмыс істейді (орнату
кезінде таңдалады). Құжаттама қазақ тілінде де бар.

## Орнату

Барлығы сервер компьютерінде, оқушылар компьютерлеріне SSH арқылы қатынауы
бар пайдаланушының атынан жасалады.

**1. Telegram-да бот жасаңыз.** @BotFather-ді ашып, `/newbot` жіберіңіз
және сұрақтарға жауап беріңіз. Ол берген токенді сақтап қойыңыз
(`123456789:AAE…` сияқты көрінеді). Оны құпиясөз сияқты сақтаңыз.

**2. Оқушылар компьютерлерін тізімдеңіз.** Олар Ansible инвентарь файлына
жазылады. Компьютерлерді Ansible арқылы басқарып жүрсеңіз, өз
инвентарыңызды алыңыз. Әйтпесе `~/ansible/hosts.yml` файлын жасаңыз:

```yaml
students:
  hosts:
    pc-01: { ansible_host: 192.168.1.101 }
    pc-02: { ansible_host: 192.168.1.102 }
    pc-03: { ansible_host: 192.168.1.103 }
  vars:
    ansible_user: admin        # SSH арқылы кіретін пайдаланушы
```

Сол жақтағы атауды (`PC-01` болып көрсетіледі) оқушылар боттан көреді. SSH
пайдаланушысы `sudo`-ны құпиясөз сұратпай орындай алуы керек; әйтпесе
Ansible құжаттамасында сипатталғандай `ansible_become_password` қосыңыз.

**3. Орнатқышты жүктеп, іске қосыңыз.**

```bash
sudo apt install git
git clone https://github.com/ts-pvl/attendance-checker.git
cd attendance-checker
./deploy/install.sh
```

Орнатқыш бірнеше сұрақ қояды:

| Сұрақ | Не деп жауап беру керек |
|---|---|
| Inventory file (инвентарь файлы) | 2-қадамдағы файл. |
| This PC's IP address (осы компьютердің IP-мекенжайы) | Сервердің мектеп желісіндегі мекенжайы. Кейін ол өзгермеуі керек. |
| Bot token (бот токені) | 1-қадамдағы токен (терген кезде көрінбейді). |
| Time zone, language (уақыт белдеуі, тіл) | Мысалы `Asia/Almaty`, `ru`. |
| Alert ids (хабарландыру ID-лері) | Міндетті емес. Жүйе істемей қалғанда хабар алатын қызметкерлердің Telegram ID-лері. Әзірге бос қалдыруға болады. |
| Username, password (аты мен құпиясөз) | Әкімші панеліне арналған алғашқы есептік жазбаңыз. |
| Deploy to the PCs now? (компьютерлерге орнату керек пе?) | `y`. Алдымен бір компьютерде байқап көру үшін: `./deploy/install.sh --limit pc-01`. |

Соңында ол әкімші панелінің мекенжайын шығарады, мысалы
`http://192.168.1.10:8080/admin`.

**4. Оқушыларды қосыңыз.** Әкімші панелін сервердегі немесе қызметкер
компьютеріндегі браузерде ашыңыз (оқушы компьютерінен кіруге тыйым
салынған). Кіріп, мынаны жасаңыз:

1. *Ученики → Импорт или обновление из CSV* (Оқушылар → CSV-ден импорттау).
   Файлда `имя` және `группа` (немесе `name` және `group`) бағандары болуы
   керек, мысалы:

   ```csv
   имя,группа
   Айгерім Садықова,Python-1
   Тимур Ахметов,Go-2
   ```

2. *Создать ссылки для всех непривязанных* (байланыстырылмағандардың бәріне
   сілтеме жасау) батырмасын басып, парақшалары бар бетті басып шығарыңыз.
3. Әр оқушыға өз парақшасын беріңіз. Оқушы сілтемені бір рет ашады (немесе
   парақшадағы QR-ды сканерлейді), сонда бот «Аккаунт привязан: …»
   (аккаунт байланыстырылды) деп жауап береді.

**5. Тексеріңіз.** Оқушы компьютеріне кіріп, QR-кодты сканерлеңіз және
оқушының *Сегодня* (Бүгін) бетінде пайда болғанына көз жеткізіңіз.

## Жаңарту

```bash
cd attendance-checker
git pull
./deploy/install.sh
```

Орнатқыш бұрынғы жауаптарды есте сақтайды. `./deploy/install.sh --pcs-only`
тек оқушылар компьютерлеріне орнатады (мысалы, біреуін қайта орнатқаннан
кейін), ал `./deploy/install.sh --help` барлық параметрлерді көрсетеді.

## Жиі қойылатын сұрақтар

**Әкімші панелі «forbidden» деп жазады.** Ол тек мектеп желісінен ашылады
және оқушы компьютерінен ешқашан ашылмайды. Оны серверде немесе қызметкер
компьютерінде ашыңыз.

**Орнату кезінде оқушы компьютері өшірулі болды.** Орнатқыш мұндай
компьютерлерді соңында тізіп, кейін орындайтын команданы көрсетеді.

**Компьютерде QR-коды бар бет ашылмайды.** Компьютердің IP-мекенжайы
инвентарьдағы мекенжаймен сәйкес келетінін тексеріп,
`./deploy/install.sh --pcs-only` командасын орындаңыз.

**Оқушы бүгін телефонсыз келді.** Әкімші рөлі бар қызметкер келуді оқушы
бетінде себебін көрсетіп, қолмен қосады.

**Оқушылар туралы не сақталады?** Аты, тобы, Telegram ID, келу және кету
уақыты, қызметкерлердің түзетулері. Оқушының компьютерде не істейтіні
туралы ештеңе сақталмайды. Барлық дерек сіздің серверіңізде қалады.

**Интернетсіз жұмыс істей ме?** Серверге Telegram-мен байланыс қажет.
Оқушылар компьютерлеріне тек сервермен байланыс қажет.
